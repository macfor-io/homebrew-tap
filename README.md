# macfor Homebrew Tap

Homebrew tap for [macfor](https://github.com/macfor-io/macfor-community), the
open-source macOS forensic artifact collector.

## Install

```bash
brew install macfor-io/tap/macfor
```

Or tap first, then install by name:

```bash
brew tap macfor-io/tap
brew install macfor
```

Upgrade with `brew upgrade macfor`.

The release binaries are unsigned. The cask strips the
`com.apple.quarantine` attribute on install, so Gatekeeper does not block the
first run.

macfor needs **Full Disk Access** (granted to your terminal) and usually
`sudo` to read protected artifacts. See the
[collector README](https://github.com/macfor-io/macfor-community#readme).

## How this tap is maintained

Do not edit `Casks/macfor.rb` by hand. GoReleaser regenerates it on every
tagged release of `macfor-community`. The `homebrew_casks` block in that
repo's `.goreleaser.yaml` controls it.

The release workflow pushes here over SSH with a write deploy key on this repo.
Its private half is the `HOMEBREW_TAP_DEPLOY_KEY` secret on
`macfor-io/macfor-community`.

Prereleases (for example `v0.2.0-rc.1`) are not published to the tap.

## Layout

```text
Casks/
  macfor.rb   # generated by GoReleaser — do not edit
```
